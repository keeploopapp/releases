# Keeploop releases

Downloads and the automatic update feed for [Keeploop](https://keeploop.app), the personal context layer for your AI.

Keeploop is a Mac menu bar app that lets the AI apps you use (Claude, ChatGPT and Codex, Cursor and others) read your Mail, Messages, Calendar, Notes and Slack, with you deciding what each one can see and do. Everything stays on your Mac.

This repository holds release builds only. Keeploop checks it for updates.

Questions or problems: help@keeploop.app
